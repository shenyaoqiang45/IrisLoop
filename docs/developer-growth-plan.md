# IrisLoop developer growth plan (AI + projection)

Cycling retail sits with a separate sales team. You are the **brand experience officer for IrisGreen**:
share thinking and live iteration on X, land open code in **IrisLoop** on GitHub, and convert through
the hardware storefront. IrisLoop is the open quickstart that helps people unbox and play — not the
consumer brand. This is Build in Public, not a marketing matrix account.

| Role | Channel | Cadence | Red line |
| --- | --- | --- | --- |
| IrisGreen brand experience | X: thinking + real laser shots | Continuous iteration | Cycling retail KPI ≠ this line |

**Org boundary:** This line does not own the 100k cycling-unit target. Show one person seriously
playing with light and AI — think, build, show, revise. North stars remain IrisGreen hardware orders
(via the live storefront for now) plus IrisLoop reproductions/submissions. Reach comes from presence,
not paid media.

---

## 0. Brand experience OS

Repo folders:

- `experience/field-notes` — drafts for X / public thinking
- `experience/laser-log` — laser capture indexes and notes
- `experience/iteration-log` — iteration journal (`private/` stays local)
- `hub/submissions` — submission guidelines and queue
- `hub/featured` — weekly featured work

| Dimension | Practice |
| --- | --- |
| Who you are | Not an ad account — the first player: run the loop, hit walls, swap models, rewrite prompts, then explain the judgment. |
| What X gets | Thinking (why this model / medium) + seeing (laser footage) + changing (next iteration). Imperfection is fine. |
| Link to code | Substantial ideas become commits / demos / benchmarks. X is the stage; the IrisLoop repo is delivery. |

### Cadence

| Cadence | Suggestion | Goal |
| --- | --- | --- |
| 3–5 X posts / week | 2 thinking posts + 1–2 Laser Shots + optional Q&A / amplify a submission | Sustainable, not burnout |
| One visible iteration / 2 weeks | A clear delta in README / scripts / eval | Prove “always iterating” |
| One long thread / month | Stage review: AI understanding, 1bpp rules, Play Kit feedback | Trust for newcomers |
| Fixed column names | Field Notes / Laser Log | Fans know what to expect |

**Voice:** fewer slogans, more judgments — “K3 read the silhouette / missed the stripes”,
“generation was too busy so we switched to I2V”. Readers want taste and presence, not brand copy.
Sales appear naturally as “reproduce it → Buy Play Kit”, not as a hard sell every post.
